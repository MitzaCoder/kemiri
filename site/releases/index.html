Release notes

What’s new in Kemiri

Every release, newest first: what changed, why it matters and how to update. Kemiri is an early pilot, so releases come often.

  1. 17 November 2026

    v0.1.0-pilot.6 Latest

    Background jobs you can follow, task states you can trust

    Main chat and background jobs get names, states and a switcher. Tasks show what is really happening. Review a report by pointing at it. Plus project skills, a 12/24-hour clock and the candlenut.

    Read the release notes →
  2. 13 November 2026

    v0.1.0-pilot.5

    One name, one command

    Aiki finished becoming Kemiri: one kemiri command, a new home at kemiri.dev, and videos that play again in the installed web app.

    Notes and downloads on GitHub ↗
  3. 13 November 2026

    v0.1.0-pilot.4

    The first Kemiri release

    HTML reports open as real pages, artifacts keep their history, and the backend can update itself after you confirm. The bridge for anyone coming from pilot.3 or earlier.

    Notes and downloads on GitHub ↗
  4. 12 November 2026

    v0.1.0-pilot.3

    Smoother MCP sign-in

    Notion sign-in fixed on local installs, a sign-in link you can finish in another browser, and the backend version shown in the corner.

    Notes and downloads on GitHub ↗
  5. 12 November 2026

    v0.1.0-pilot.2

    Attachments, MCP servers and one executable

    Attach files to chat, connect MCP servers, install a single executable, and see when an update is available.

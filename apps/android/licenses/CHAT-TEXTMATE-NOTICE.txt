Chat syntax grammars and Catppuccin themes

The npm packages tm-grammars 1.32.22 and tm-themes 1.12.12 supply the bundled assets.
Their package licences and the applicable upstream notices are reproduced below.
The asset index records the pinned source URL for every grammar.
Catppuccin themes retain token styles only. Kemiri adjusts Latte token foregrounds for contrast.
Kemiri repairs the misplaced end and name fields in XML’s ASP comment rule and
splits an equivalent JS/TS look-behind for the bundled regex engine.
